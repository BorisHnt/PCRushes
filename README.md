# PCRushes

Guide statique publié sur GitHub Pages pour aider les tuteur·rices à préparer et conduire les reviews des rushs de Piscine C.

## Site publié

https://borishnt.github.io/PCRushes/

## Catégories

- Toolbox : posture, déroulé, feedback et situations sensibles
- Exams : préparation, entrée, surveillance et incidents d’examen
- Rush 00 : rectangles, cas limites et compréhension collective
- Rush 01 : parsing, solveur 4x4, récursivité et mémoire
- Rush 02 : dictionnaire, grands nombres, parsing de fichier et gestion mémoire
- Trolls : rappel sécurité et blagues terminal temporaires, sans dégâts

## Utilisation

Ouvrir le site publié ou lancer `index.html` directement dans un navigateur pour travailler hors ligne.

Les pages utilisent des slugs dans l’URL :

- `#toolbox`
- `#exams`
- `#rush-00`
- `#rush-01`
- `#rush-02`
- `#trolls`
