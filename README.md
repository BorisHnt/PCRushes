# PCRushes

Guide statique local pour aider les tuteur·rices à préparer et conduire les reviews des rushs de Piscine C.

## Catégories

- Rush 00 : rectangles, cas limites et compréhension collective
- Rush 01 : parsing, solveur 4x4, récursivité et mémoire
- Rush 02 : dictionnaire, grands nombres, parsing de fichier et gestion mémoire
- Toolbox : posture, déroulé, feedback et situations sensibles

## Utilisation

Ouvrir `index.html` dans un navigateur.
